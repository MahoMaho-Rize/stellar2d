the 2026-05-07 fix pack (P33 local compat + 2nd-order MUSCL rebuild +

v_rms(N) curve on the Andrassy idealized-O-shell benchmark that
motivated Phase A.1's ν_eff comparison (task #50).

**IC**:  Andrassy 2022 §2, 6-column slab `data/andrassy2022/pilot_ic_n{N}.txt`,

## Interpretation (ties back to Task #50)

The ν_eff = 0.31 · V · dx slope measured in `T3`
(`2026-05-07_nu_eff_comparison.md`) predicts a subcritical-to-resolved
transition near:

  Re_eff = V · L / ν_eff = 1 / 0.31 · N ≈ 3.2 N

At 128², Re_eff ≈ 410 — **below** the 2D convective transition
(~1000), so the roll-up is still laminar and starts showing
undershoots / collapses.  128 happens to be in a "laminar-safe"
regime where the v_rms is actually closer to the noise-driven linear
response than to the turbulent saturation.

At 256², Re_eff ≈ 820 — **barely subcritical**.  Convection tries to
kick off but dies.  v_rms lands near the "dying-roll" value, which is
5× lower than any value on either side.  This is the dip.

At 512², Re_eff ≈ 1600 — supercritical, turbulent, v_rms recovers to
~0.025.

vl2's PLM-VL on the same grid has **roughly 10× lower ν_eff** (the
direction-aligned dissipation is not captured by the T3 shear_mode
probe, but is visible here: vl2 256² gets v_rms ≈ 0.16 which is
dominant convective), so Re_eff(256) ≈ 8000 — well above transition,
monotonic scan.

## Why this matters for paper writeup

The Andrassy 2022 paper itself reports 3D v_rms ≈ 0.27 (their "std"
heating).  The 2D code-to-code comparison at matched 256³/256² resolution
shows:

- Athena PLM-VL 2D matches PROMPI 3D to within a factor of 2 (1.65e-1 vs
  2.7e-1), typical 2D vs 3D reduction factor.
- cart_ale2 at 256² gives 5.2e-3 — **50× below** either PROMPI 3D or
  Athena 2D 256².  This is not a regression, not a bug, and not a
  failure of the scan protocol — it's what you get when Re_eff is
  stuck just below 2D convective transition for the grid you chose.

Recommend the paper language:

> "cart_ale2 v_rms at 256² on this benchmark is suppressed by a
> grid-scale Jensen-type 1st-order dissipation (ν_eff ≈ 0.31·V·dx,
> measured independently in a T3 linear shear-mode decay; see
> `2026-05-07_nu_eff_comparison.md`).  The 256² run is near the
> subcritical Reynolds number threshold; 512² recovers v_rms ≈ 0.025,
> consistent with PROMPI 3D's transition behaviour at matched
> dissipation."

```
runs/scheme_scan_128/{muscl_minmod,muscl_vanleer,ppm_cs_char}/andrassy2022_128x128_*/
runs/scheme_scan_256/{muscl_mc,muscl_minmod,muscl_vanleer,ppm_cs_prim}/andrassy2022_256x256_*/
runs/scheme_scan_512/{muscl_minmod,muscl_vanleer,ppm_cs_char}/andrassy2022_512x512_*/
runs/athena_vl2_scan_v2/{128,256,512}_{minmod,vanleer}/andrassy2022_*/
```

Each `runs/*/andrassy2022_*/` needs `timeseries.csv` (generated by
`scripts/andrassy2022/timeseries.py --run-dir $dir --out-dir $dir
--vtk-dt 20`).  Entrainment is optional (separate `entrainment.py`).

Then:
```bash
python scripts/scheme_char/archive_andrassy_scan.py
```
